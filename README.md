# Nigerian Nurses Forum for Excellence Landing Page

A responsive, self-contained landing page prepared for GitHub deployment.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — mobile navigation
- `assets/forum-logo.jpg` — supplied forum logo
- `assets/forum-flyer.jpg` — supplied promotional flyer

## Quick deployment
1. Copy the folder contents into the desired location in your GitHub website repository.
2. If this should be a subpage, place the folder inside your site, for example:
   `/nurses-forum/index.html`
3. Commit and push to GitHub.
4. If you use GitHub Pages, the page will become available under that path after deployment.
